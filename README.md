# Mokepon

Juego multijugador de combate por turnos hecho con HTML, CSS, JavaScript (Canvas) y un backend en Node.js + Express. Proyecto del Curso de Programación Básica de Platzi.

## Enlaces

- Repositorio: https://github.com/sasaelcrack/mokepon
- Certificado del curso: https://platzi.com/p/salazarsamuel0719/curso/3208-programacion-basica-2022/diploma/detalle/
- Copia del certificado: [certificado-platzi.pdf](./certificado/certificado-platzi.pdf)

## Cómo ejecutarlo

```bash
npm install
npm start
```

Abre http://localhost:8080 en dos pestañas para probar el modo multijugador.

## Cómo se juega

1. Elige tu Mokepon.
2. Muévete por el mapa (botones o flechas del teclado) hasta chocar con otro jugador.
3. Elige tus 5 ataques. Agua le gana a fuego, fuego a tierra y tierra a agua.
4. Gana quien tenga más victorias.
